## Цель

Обучить модель ранжирования на готовых признаках: выбрать функцию потерь, подобрать параметры и правильно разбить данные на обучение и валидацию по запросам.

## Задача

Даны около 10 000 поисковых запросов из VK MARCO и для каждого несколько десятков документов-кандидатов из топа поиска VK. Для каждой пары запрос–документ посчитаны 67 признаков: BM25 и другие текстовые модели по зонам документа, близость слов запроса, признаки URL и домена. Тексты и идентификаторы не выдаются, только признаки.

- 7 000 обучающих запросов с оценками от 0 до 3;
- 3 000 тестовых запросов с закрытыми оценками: половина в публичном лидерборде, половина в приватном.

Кандидатов каждого тестового запроса нужно упорядочить так, чтобы релевантные оказались выше. Метрика: nDCG@10, усреднённая по запросам.

Запросы здесь другие, не те, что в ДЗ2.

## Данные

Скачайте данные на вкладке Data соревнования (или `kaggle competitions download -c learning-to-rank-homework-vk-ir-hse-fall-2026`). Все файлы в UTF-8.

| Файл | Формат |
|---|---|
| `train.csv` | с заголовком: `QueryId`, `Label`, дальше признаки |
| `test.csv` | с заголовком: `ObjectId`, `QueryId`, дальше те же признаки |
| `features.md` | описание каждого признака |
| `sample_submission.csv` | пример сабмишна со случайными скорами |

`QueryId` — номер запроса внутри этого ДЗ, по нему группируются документы одного запроса.

## Что нужно сделать

1. Реализовать `solution.py` на основе шаблона из этой папки. Скрипт запускается в двух режимах:
   ```bash
   ./solution.py --train --model_file=model.bin PATH-TO-DATA
   ./solution.py --model_file=model.bin --submission_file=submission.csv PATH-TO-DATA
   ```
   Первая команда обучает модель на `train.csv` и сохраняет её, вторая загружает модель и пишет сабмишн: CSV с заголовком `ObjectId,Score`, по строке на каждый объект из `test.csv`.
2. Побить бейзлайн на Kaggle. Бейзлайн: `CatBoostRanker` с функцией потерь YetiRank и 200 итерациями на всех признаках, остальные параметры по умолчанию.
3. Подбирать параметры только на обучающих запросах. Train делите на части по запросам, а не по строкам.

### Что можно

- любые модели для табличных данных: CatBoost, LightGBM, XGBoost, линейные модели, нейросети;
- функции потерь для ранжирования: LambdaMART, YetiRank, pairwise, listwise;
- подбор гиперпараметров, кросс-валидация по запросам, ансамбли;
- преобразования готовых признаков: нормировка внутри запроса, ранги, разности и отношения, отбор признаков.

### Что нельзя

- Новые признаки из текстов документов и запросов, внешние данные и разметка.
- Попытки восстановить тексты или исходные идентификаторы запросов и документов. `solution.py` читает только файлы этого ДЗ.

## Окружение

Заведите отдельный venv только под это ДЗ (см. [README в корне репозитория](../../README.md)) и ставьте туда только то, что реально используете.

## Как сдавать

1. Побейте бейзлайн на Kaggle.
2. Прикрепите к заданию на платформе ссылку на свой репозиторий на GitHub. Если он приватный, дайте доступ преподавателю. В репозитории должны лежать:
   - `solution.py`, который запускается двумя командами выше и воспроизводит ваш сабмишн;
   - `requirements.txt` с зависимостями из вашего окружения (`pip freeze > requirements.txt`);
   - `README.md` с вашим ником на Kaggle, скором на публичном лидерборде и лучшими гиперпараметрами.

Проверяющий восстановит ваше окружение из `requirements.txt`, запустит обе команды на Linux без GPU и сверит сабмишн со скором на Kaggle. Зафиксируйте seed. Обучение должно занимать не больше 30 минут и укладываться в 8 ГБ оперативной памяти.
