# ДЗ 4. Нейросетевое ранжирование

## Цель

Сделать один нейросетевой признак, который сопоставляет текст запроса и документа, и ранжировать документы только по нему.

## Задача

Постановка как в [ДЗ 2](../hw2-text-ranking/): для каждого тестового запроса VK MARCO переранжировать документы-кандидаты из топа поиска VK. Метрика — **nDCG@10**, итог по приватной части лидерборда.

- около 5 000 обучающих запросов с оценками от 0 до 3;
- 2 000 тестовых запросов, оценки скрыты: половина идёт в публичный лидерборд, половина — в приватный;
- весь корпус VK MARCO: около 1,26 млн документов, 16.8 ГБ. Этот же файл понадобится в финальном проекте.

Корпус целиком в память не помещается: читайте его построчно и оставляйте только кандидатов своих запросов.

## Данные

Формат как в ДЗ2: `vkmarco-docs.tsv`, `vkmarco-doctrain-queries.tsv`, `vkmarco-doctrain-qrels.tsv`, `vkmarco-doceval-queries.tsv`, `objects.csv`, `sample_submission.csv`. Сабмишн — CSV с заголовком `ObjectId,Score`.

## Что нужно сделать

1. `train.py` дообучает модель и сохраняет веса.
2. `solution.py` по весам строит сабмишн:
   ```bash
   ./solution.py --model_dir=MODEL-DIR --submission_file=submission.csv PATH-TO-DATA
   ```
3. Побить бейзлайны на Kaggle:
   - первый — готовая модель эмбеддингов без дообучения, ранжирование по косинусу;
   - второй — дообученный кросс-энкодер.

### Что можно

- предобученные модели с открытыми весами: `cointegrated/rubert-tiny2`, `intfloat/multilingual-e5-small`, `DeepPavlov/rubert-base-cased` и подобные;
- дообучение в виде bi-encoder или cross-encoder, любые функции потерь, подбор негативов;
- предобработка текста: выбор зон документа, обрезка длинного Body.

### Что нельзя

- Готовые переранжировщики, уже обученные на релевантность: `BAAI/bge-reranker-*`, кросс-энкодеры, обученные на MS MARCO, и подобные.
- Смешивать скор нейросети с BM25 или другими признаками: итоговое ранжирование — только по одному нейросетевому скору.
- Внешние данные и разметку, платные API.

## Окружение

Заведите отдельный venv только под это ДЗ (см. [README в корне репозитория](../../README.md)). Нужна одна GPU: хватит бесплатной в ноутбуках Kaggle.

## Как сдавать

1. Побейте бейзлайн на Kaggle.
2. Прикрепите к заданию на платформе ссылку на свой репозиторий на GitHub. Если он приватный, дайте доступ преподавателю. В репозитории:
   - `train.py` и `solution.py`;
   - `requirements.txt`;
   - `README.md` — ник на Kaggle, скор на публичном лидерборде, ссылка на веса, время обучения и инференса.

Веса не кладите в репозиторий, выложите их в облако или на Hugging Face. Проверяющий запустит `solution.py` с вашими весами на одной GPU и сверит сабмишн со скором на Kaggle. Инференс должен занимать не больше часа.
